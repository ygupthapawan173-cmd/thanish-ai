# V100.5 Smart Actions candidate (based on V100.4)
The Smart Gateway (including configured AICredits) now has a single-request structured text action proposal path for natural language. Validated allowlist: installed app launch, flashlight, media volume set/adjust, system settings, dialer for manual confirmation, browser search and battery. Maximum three distinct actions per response. Normal Q&A remains text. Existing direct device command fast path remains. Dynamic app selection reads visible launcher labels on device, prefers exact match, refuses ambiguous matches. Calls are dial-only on the new gateway route. No package inventory is sent to the gateway. Actual user command classification is model dependent; prompt guidance and local filters are not a guarantee against semantic errors. Existing Gemini path was not redesigned. No new cloud voice packs, background wake or local brain added. No screen lock launch guarantee. On-device testing and Android compilation pending. The existing cloud-only configuration and voice presets are preserved.

Local verification: 49/49 standalone Kotlin policy checks, 15/15 integration source checks, prior V47 through V104 source guards passed. The new JUnit test is included but not run through Android Gradle locally.
