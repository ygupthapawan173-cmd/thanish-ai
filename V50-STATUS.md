## Known tradeoffs and size
V47 APK compressed entries: Telugu 60.21 MiB, English 40.51 MiB, speaker 13.28 MiB, LLM native library 12.25 MiB. V47 total ~173.6 MiB. Subtracting Telugu and LLM native entries yields ~101.1 MiB before other changes. Estimate ~95–110 MiB, not 50–65 MiB; actual build measurement required. Reaching lower target while keeping current custom wake and speaker verification requires a separately validated compatible smaller model/architecture.
Owner-filtered Telugu background commands are no longer available: fail closed, do not bypass owner verification. Owner verification on English wake and English commands retained. Locked screen uses local-only recognition for privacy; if an Android on-device pack is absent, wake can detect but general command recognition may not be available. Cloud conversation requires internet, provider/API credentials, unlocked screen. No new voice model or accuracy guarantee. Previously imported local model files on installed devices are not silently deleted.
