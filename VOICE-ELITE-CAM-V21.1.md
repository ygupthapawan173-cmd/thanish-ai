# V21.1 ELITE CAM Voice Master — test candidate
Base: V20.5 ELITE voice master; no visual resource or Compose screen changes. The prior ELITE CAM repository overlays informed routing and diagnostics, not an exact port of its unavailable core source. V21 Lite charging/share additions are deliberately not merged in this voice-only candidate.

New changes: foreground Vosk English fallback after bounded Android ASR retries; on-device-first recognition with system fallback when permitted; mic lease handoff retry; capability-specific HTTP 400 fallback, additional transient server codes, removal of an unverified chat fallback identifier; zero PCM and frame watchdog; optional owner filter separate from enrollment, short wake with absent vector permits only subsequent verified command; voice profile notification control; foreground/background spoken acknowledgement with timeout fallback; background session context bounded to two turns in memory; local-only lock recognition; TTS config applied after initialization. Owner verification is an experimental convenience filter, not authentication. The filter defaults off even for migrated profiles; English-only when enabled. Screen-locked general cloud Q&A remains blocked. Android 16 foreground-service and installed Telugu data restrictions remain. No cloud keys added. Existing background Live, server interruption, adaptive silence, Bluetooth Live routing, model packs, style settings, continuous conversation and diagnostics retained. Full non-Live hands-free barge-in, native Telugu offline model, calibrated owner accuracy, token-streaming text TTS and complete device-level self-test are not delivered as verified capabilities. Battery performance, wake reliability, API response and actual Android runtime remain unverified. UI unchanged; notification actions modified. Existing Android compile tests run in CI; local host policy smoke test passed only.
