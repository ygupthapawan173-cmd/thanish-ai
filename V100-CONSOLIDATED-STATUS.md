- Engineering orchestrator: synchronize start/stop and keep active job until cancellation completes; check CI for exact commit for a longer bounded window (30 polls, 10-second intervals); only automatically repair actual failure, not cancellation/timeouts; keep progress monotonic. Existing isolated branches, draft PR and human merge review retained. GitHub synchronous calls may finish after cancel; stop cannot reverse an already accepted remote action. No claim of autonomous end-to-end upgrade success.
- GitHub: bound JSON responses at 2 MiB, add 60-second call timeout, validate source type/encoding/SHA and strict UTF-8, reject oversized source, validate isolated branch before writes, propagate cancellation, redact and cap failure summaries. Large files still require explicit smaller source selection. GitHub connector is not used for app runtime; runtime requires owner-configured token and actual source tree plus build workflow, not ZIP-only repository. No live GitHub mutation tested.
- Updater: unique temporary encrypted settings backup; remove partial backup on write failure; reject zero-progress, empty or incomplete download streams; retain existing hash, APK package, signer and version checks, and Android owner confirmation. No APK installed, no automatic rollback guaranteed.
- Vision: reject recycled bitmaps, calculate bounded aspect-preserving dimensions, reject JPEG payload >4 MiB; existing image path retained. No camera device test.
- Settings: bounded query, case-insensitive multi-term match, safe aliases fallback and actual visible category count. Existing V100 interface retained; this is targeted refinement, not 100 UI upgrades or a new visual redesign.
- Diagnostics: unavailable hardware readings reported as unavailable rather than 0%, 30 C, or healthy; no-issue message now limited to snapshot. Existing thermal-aware rendering retained.
