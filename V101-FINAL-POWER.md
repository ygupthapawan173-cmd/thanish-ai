# V101 Final Power candidate
Base: exact V100.5 Smart Actions archive. Version code 106, unchanged package. New optional AICredits Cloud Neural Voice integration using the documented /v1/audio/speech endpoint, six OpenAI speakers and four Sarvam Bulbul v2 speakers, English standard/HD, automatic script-based language routing, saved selections and paid preview. Disabled by default; no API key embedded. One request per eligible utterance, max 1,000 characters and 8 MiB audio. HTTPS endpoint pinned to AICredits; redirects and automatic transport retries disabled. Audio is held in bounded memory, not saved as a file. 18-second call timeout, cancellation, foreground/lock/privacy/credential guards, audio focus, playback watchdog and Android TTS fallback before playback only, 30-second cooldown after failed cloud synthesis. Playback speed is applied where supported. Longer replies, disabled paid mode and other providers use existing Android TTS. Cloud voice is not true streaming and can increase latency and cost. Voice names are provider speaker IDs, not movie character clones. Audio-only model families excluded from chat routing. Old offline recognition pack download controls removed from voice panel; Android TTS data controls remain. Existing offline assets remain for build compatibility; offline wake and local brain remain disabled/removed. Existing smart actions, UI theme, memory, gateway settings and self-coding preserved. New cloud voice preferences stored locally, not included in portable backup.
