## Source changes
- 14 category routes with native Compose Obsidian colors, search, back navigation, settings persistence, high contrast controls, and BuildConfig version label. Existing Home / Orb / Clean List content unchanged except settings callbacks.
- Existing settings controls regrouped. Memory and verified update/system-health actions open existing working screens. Owner profile actions call the existing foreground service and retain enrollment/lock/mic safeguards. Custom assistant name and reply style affect chat prompt; they do not change the wake phrase.
- Gemini model discovery separates text, Live (bidi method), and TTS audio-only catalog; text candidates exclude known incompatible model names. API ping uses compatible fallback chain, reports actual model and nonempty text response, and saves successful chat model. Specific modality/tool errors and HTTP 429 can trigger bounded model fallback; authentication errors are not retried as model errors.
- Independent prefer-offline speech option, explicit Telugu offline Vosk routing, language error 12/13 fallback, and clear optional Android provider download messaging. All three bundled pack checks retained.
- TTS preview uses actual selected eligible engine voices, configured pitch/speed, and reports engine status. Playback failure can retry a different eligible voice. Android does not expose trustworthy gender metadata: no inferred male/female labels or fabricated voice packs. Gemini TTS catalog is informational; spoken replies remain Android TTS. No cloud TTS playback implementation.

## Verification and limitations
- 12 pure Kotlin smoke assertions passed for model classification, fallback and voice pack policy; additional JUnit tests included in CI.
- ZIP checked for integrity. No local Android SDK/Gradle build or real device/API test available. Full Android compile, regression tests, signature and model-pack verification must run in GitHub Actions after source upload.

Not all options from concept preview have independent implementations; unsupported options omitted rather than mocked.
