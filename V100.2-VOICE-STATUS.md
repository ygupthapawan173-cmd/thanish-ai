# V100.2 voice collection integration candidate
Base: V100.1 wake recovery source. Package ID unchanged; versionCode 102. Existing wake logic unchanged except wiring the optional Live speaker selection. AICredits gateway and API budget policy unchanged.

- Added six Android TTS pitch/rate presets (Commander, Gentle, Bright, Narrator, Quick, Soft), retaining the five existing presets. These are styles, not independent speaker models.
- Existing Android TTS catalog continues to list actual eligible English/Telugu engine voices, with separate language selections. Added Telugu/English preview shortcuts in style settings. Availability depends on installed speech engine and data; lock-screen/privacy restrictions remain unchanged.
- Added six selectable prebuilt Gemini Live speakers (Kore, Puck, Charon, Fenrir, Aoede, Zephyr), plus provider default. Preference saved and supplied in foreground/background Live session setup. Default omits speechConfig to preserve previous behavior. Takes effect next Live session; requires compatible Google Live model and separate Google API key, may cost money. No cloud calls made here; AICredits gateway TTS path still uses Android TTS.
- No API credentials bundled. Source tests only; Android Gradle compilation, provider acceptance, actual voice playback, wake regression on device and signing continuity unverified. If the selected Live model rejects a voice, choose Provider default.
